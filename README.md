Repo for the best team at Hack Dearborn 5
<hr>
StudyAthon uses agents to take in user input (like study notes and lecture notes/slides) to create multiple choice questions to quiz the user in an infinite loop unless all answers are correct. When the user answers a quesiton correct, the quistion and answer will be rephrased and put back into the learning loop.
